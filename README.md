# Tech Learning Log

> **업무에서 배우고, 직접 확인하고, 그 과정을 기록합니다.**

---

## About

안녕하세요? 찾아주셔서 감사합니다.

이곳은 **네트워크·서버 유지보수 및 보안 솔루션 기술지원 업무를 수행하며 습득한 지식과, 개인적으로 공부하며 얻은 기술을 기록하는 공간**입니다.

단순히 주어진 유지보수 작업을 반복하는 것에서 그치지 않고,
업무를 수행하면서 마주한 문제에 대해 왜 이렇게 동작하지?라는 질문을 던지고 그 원리를 직접 탐구하고자 합니다.

특히 제조사로부터 충분한 기술적인 답변을 얻지 못한 문제나, 공식 문서만으로는 원인을 명확하게 파악하기 어려운 문제에 대해서는 직접 비슷한 환경을 구성하고 로그와 설정을 분석하며 원인을 찾아가는 과정을 기록합니다.

제가 직접 확인하고, 분석하고, 결과물을 만들어냈다는 **기술적인 흔적과 증거를 남기는 것**이 이 저장소의 가장 큰 목적입니다.

---

## Why I Keep This Log

편입을 통해 전공을 다시 시작하면서 남들보다 늦게 IT 분야에 뛰어들었습니다.

그렇기 때문에 더 많이 배우고, 더 많이 기록하고 싶었습니다.

업무를 하다 보면 같은 작업을 반복하면서 어느 순간 내가 얼마나 성장했는지 체감하지 못할 때가 있습니다.

하지만 하나의 문제를 해결하고, 과정을 거쳐 하나의 결과물을 남기면 **내가 어디에서 출발했고, 어디까지 나아왔는지를 확인할 수 있습니다.**

기록은 단순한 메모가 아니라고 생각합니다.

> **무언가를 배우고, 고민하고, 직접 해결했다는 흔적이자
> 내가 성장하고 있다는 것을 확인할 수 있는 증거**

이 저장소에는 그 흔적을 하나씩 쌓아가려고 합니다.

## My Principle

> **"그냥 된다"에서 끝내지 않고,
> "왜 되는지"까지 확인한다.**

업무에서 발생하는 문제를 단순히 해결하는 것에 그치지 않고,

**문제 → 분석 → 원리 이해 → 재현 → 검증 → 기록**

의 과정을 통해 하나의 기술 경험으로 만들어가는 것을 목표로 합니다.
