# 라우터와 라우팅 알고리즘

## 라우터

- 라우터(Router): 라우팅 기능을 수행하는 네트워크 장치로, 라우팅 정보를 참조하여 데이터 패킷의 경로를 결정하고 목적지 네트워크로 전달한다.
- 서로 다른 네트워크를 연결하는 장비
  - LAN-LAN 연결
  - LAN-WAN 연결
  - 서로 다른 IP 네트워크 간 연결
- 데이터 패킷이 목적지까지 전달될 수 있도록 최적의 경로를 결정한다.
- 라우팅 프로토콜을 이용하여 네트워크의 경로 정보를 학습하고 라우팅 테이블을 구성한다.

### 라우터의 주요 기능

1) 경로 설정(Routing)
   - 데이터 패킷이 출발지에서 목적지까지 도달할 수 있는 경로를 확인한다.
   - 여러 경로가 존재할 경우 라우팅 정보를 바탕으로 가장 적절한 경로를 결정한다.
   - 결정된 경로 정보를 라우팅 테이블에 저장한다.

2) 패킷 전달(Forwarding)
   - 목적지 IP 주소를 확인하고 라우팅 테이블을 참조하여 패킷을 다음 홉(Next Hop) 또는 적절한 인터페이스로 전달한다.
   - 라우터가 실제로 패킷을 다음 장치로 보내는 과정이다.

3) 라우팅 테이블 관리
   - 목적지 네트워크, 서브넷 마스크, 다음 홉, 출발 인터페이스, 메트릭 등의 정보를 관리한다.
   - 정적 라우팅 또는 동적 라우팅 프로토콜을 통해 라우팅 정보를 구성한다.

4) 네트워크 간 연결
   - 서로 다른 네트워크 또는 서브넷을 연결하고 네트워크 간 패킷 통신이 가능하도록 한다.

---

## 라우팅(Routing)

- 라우팅(Routing): 데이터 패킷을 목적지까지 전달하기 위한 최적의 경로를 결정하는 과정
- 라우터는 목적지 IP 주소와 라우팅 테이블을 참조하여 패킷을 전달할 경로를 결정한다.

### 라우팅의 구성

- 라우팅 방식
  1) 정적 라우팅(Static Routing)
  2) 동적 라우팅(Dynamic Routing)

- 동적 라우팅 알고리즘
  1) 거리 벡터(Distance Vector) 알고리즘
  2) 링크 상태(Link State) 알고리즘

- 대표적인 라우팅 프로토콜
  - RIP
  - OSPF
  - EIGRP

---

## 라우팅의 종류

### 1) 정적 라우팅(Static Routing)

- 네트워크 관리자가 라우팅 경로를 직접 설정하는 방식
- 네트워크 변화가 발생해도 라우터가 자동으로 경로를 변경하지 않는다.
- 설정한 경로를 수동으로 변경해야 한다.

#### 장점

- 설정이 단순한 소규모 네트워크에서 사용하기 쉽다.
- 동적 라우팅 프로토콜을 사용하지 않기 때문에 라우팅 정보 교환에 따른 네트워크 오버헤드가 없다.
- 관리자가 경로를 직접 제어할 수 있다.

#### 단점

- 네트워크 규모가 커질수록 설정 및 관리가 어렵다.
- 장애나 네트워크 변경이 발생했을 때 관리자가 직접 경로를 수정해야 한다.

---

### 2) 동적 라우팅(Dynamic Routing)

- 라우터가 라우팅 프로토콜을 사용하여 다른 라우터와 라우팅 정보를 교환하고 자동으로 경로를 학습하는 방식
- 네트워크의 변화나 장애가 발생하면 라우팅 정보를 교환하여 새로운 경로를 계산할 수 있다.

#### 장점

- 대규모 네트워크에서 라우팅 경로를 효율적으로 관리할 수 있다.
- 네트워크 장애나 변경에 따라 경로를 자동으로 변경할 수 있다.
- 관리자가 모든 경로를 직접 설정할 필요가 없다.

#### 단점

- 라우팅 정보를 교환하기 위한 네트워크 및 장치 자원이 필요하다.
- 라우팅 프로토콜의 설정 및 동작 원리를 이해해야 한다.

---

# 라우팅 알고리즘

## 1) 거리 벡터(Distance Vector) 알고리즘

- 목적지까지의 거리(Distance)와 방향(Vector)을 기준으로 최적의 경로를 결정하는 방식
- 라우터가 자신과 연결된 이웃 라우터에게 라우팅 정보를 주기적으로 전달한다.
- 목적지까지의 거리와 다음 홉 정보를 바탕으로 라우팅 테이블을 갱신한다.
- 대표적인 프로토콜
  - RIP
  - EIGRP

### 주요 특징

- 이웃 라우터와 라우팅 정보를 교환한다.
- 경로 선택에 메트릭을 사용한다.
- 일반적으로 링크 상태 방식보다 라우터가 유지하는 네트워크 정보가 적다.
- 네트워크 규모가 커질 경우 수렴 속도가 느릴 수 있다.

---

## 2) 링크 상태(Link State) 알고리즘

- 각 라우터가 네트워크의 연결 상태(Link State) 정보를 수집하고 이를 바탕으로 전체 네트워크의 토폴로지를 파악하여 최적 경로를 계산하는 방식
- 대표적인 프로토콜
  - OSPF

### 주요 특징

- 네트워크의 토폴로지 정보를 바탕으로 경로를 계산한다.
- 일반적으로 Dijkstra 알고리즘을 이용하여 최단 경로를 계산한다.
- 거리 벡터 방식보다 네트워크 변화에 빠르게 대응할 수 있다.
- 대규모 네트워크에서 많이 사용된다.

---

# 대표적인 라우팅 프로토콜

## 1) RIP

- RIP(Routing Information Protocol)
- 거리 벡터 라우팅 프로토콜
- 목적지까지의 홉 수(Hop Count)를 메트릭으로 사용한다.
- 최대 15홉까지 사용할 수 있으며, 16홉은 도달할 수 없는 경로로 간주한다.
- UDP 520번 포트를 사용한다.

### RIPv1

- RIP Version 1
- 클래스풀(Classful) 라우팅 프로토콜
- VLSM과 CIDR을 지원하지 않는다.
- 라우팅 업데이트에 서브넷 마스크 정보를 포함하지 않는다.
- 브로드캐스트 방식으로 라우팅 정보를 전달한다.

### RIPv2

- RIP Version 2
- 클래스리스(Classless) 라우팅 프로토콜
- VLSM(Variable Length Subnet Mask)을 지원한다.
- CIDR(Classless Inter-Domain Routing)을 지원한다.
- 라우팅 업데이트에 서브넷 마스크 정보를 포함한다.
- 멀티캐스트 주소 224.0.0.9를 사용하여 라우팅 정보를 전달한다.

---

## 2) OSPF

- OSPF(Open Shortest Path First)
- 링크 상태(Link State) 라우팅 프로토콜
- 최단 경로를 계산하기 위해 SPF(Shortest Path First) 알고리즘을 사용한다.
- 일반적으로 Dijkstra 알고리즘을 기반으로 최적 경로를 계산한다.
- 대규모 IP 네트워크에서 널리 사용된다.
- VLSM(Variable Length Subnet Mask)을 지원한다.
- CIDR(Classless Inter-Domain Routing)을 지원한다.
- 계층적인 네트워크 구성을 위해 Area 개념을 사용한다.
- 백본 영역은 Area 0이다.
- IP 프로토콜 번호 89번을 사용한다.

---

## 3) EIGRP

- EIGRP(Enhanced Interior Gateway Routing Protocol)
- Cisco에서 개발한 고급 거리 벡터(Advanced Distance Vector) 라우팅 프로토콜
- 일반적으로 하이브리드 라우팅 프로토콜이라고도 설명한다.
- IP 프로토콜 번호 88번을 사용한다.
- 클래스리스(Classless) 라우팅 프로토콜
- VLSM과 CIDR을 지원한다.
- 부하 분산을 지원한다.
- 동일한 비용의 경로뿐만 아니라 조건에 따라 서로 다른 비용의 경로를 이용한 불균등 비용 부하 분산도 지원한다.
- DUAL(Diffusing Update Algorithm)을 사용하여 경로를 계산하고 빠른 수렴을 지원한다.
- 인접 라우터(Neighbor)와 라우팅 정보를 교환한다.

---

# 라우팅 프로토콜 비교

| 프로토콜 | 알고리즘 | 주요 메트릭 | 특징 |
|---|---|---|---|
| RIPv1 | 거리 벡터 | 홉 수 | 클래스풀, VLSM/CIDR 미지원 |
| RIPv2 | 거리 벡터 | 홉 수 | 클래스리스, VLSM/CIDR 지원 |
| OSPF | 링크 상태 | Cost | Area 사용, SPF 알고리즘 |
| EIGRP | 고급 거리 벡터 | 복합 메트릭 | Cisco 개발, 빠른 수렴, 부하 분산 |

# 정리

- 라우터
  - 서로 다른 네트워크를 연결한다.
  - 라우팅 테이블을 참조하여 패킷의 전달 경로를 결정한다.
  - 결정된 경로에 따라 패킷을 다음 홉 또는 목적지 인터페이스로 전달한다.

- 라우팅 방식
  - 정적 라우팅
  - 동적 라우팅

- 동적 라우팅 알고리즘
  - 거리 벡터
  - 링크 상태

- 대표적인 라우팅 프로토콜
  - RIP → 거리 벡터
  - OSPF → 링크 상태
  - EIGRP → 고급 거리 벡터

- 클래스풀(Classful)
  - RIPv1

- 클래스리스(Classless)
  - RIPv2
  - OSPF
  - EIGRP
